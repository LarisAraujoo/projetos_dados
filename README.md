# Projeto de Análise de Vendas com Python

Este projeto faz uma análise simples de um conjunto de dados de vendas usando Python.

## Ferramentas utilizadas

- Python
- Pandas
- Matplotlib

## O que o script faz

1. Carrega um arquivo CSV com dados de vendas
2. Limpa os nomes das colunas
3. Calcula o faturamento de cada venda
4. Calcula o faturamento total
5. Descobre qual produto vende mais
6. Cria um gráfico de vendas por produto

## Estrutura do projeto

dados/ → arquivo de dados CSV  
scripts/ → script de análise em Python  
notebooks/ → espaço para análises futuras  
grafico_vendas.png → gráfico gerado pelo script

## Resultado da análise

O script gera um gráfico mostrando a quantidade vendida de cada produto.
